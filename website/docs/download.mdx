## Installation Instructions

### Windows

1. Download the Windows installer above
2. Run the `.exe` file as Administrator
3. Follow the installation wizard
4. Once installed, open Command Prompt or PowerShell
5. Verify installation by running: `jilebi --version`

### Linux

1. Download the Linux tarball above
2. Extract the archive: `tar -xzf jilebi-linux-x64.tar.gz`
3. Move the binary to your PATH: `sudo mv jilebi /usr/local/bin/`
4. Make it executable: `sudo chmod +x /usr/local/bin/jilebi`
5. Verify installation by running: `jilebi --version`

### macOS

1. Download the appropriate DMG file for your Mac
2. Open the DMG file
3. Drag Jilebi to your Applications folder
4. Open Terminal
5. Add Jilebi to your PATH by adding this line to your `~/.zshrc` or `~/.bash_profile`:
   ```bash
   export PATH="/Applications/Jilebi.app/Contents/MacOS:$PATH"
   ```
6. Reload your shell: `source ~/.zshrc` (or `source ~/.bash_profile`)
7. Verify installation by running: `jilebi --version`

## Getting Started

Once you have Jilebi installed, check out our [Getting Started guide](/docs/intro) to learn how to use it.

## System Requirements

- **Windows**: Windows 10 or later (64-bit)
- **Linux**: Most modern Linux distributions (64-bit)
- **macOS**: macOS 11.0 or later (Intel and Apple Silicon)
